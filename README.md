# Unity Open Source

A collection of **open-source Unity tools, editor utilities, and reusable code modules** created by **Sayan Jana (sayanforsayan)**.

This repository contains useful tools designed to improve **Unity development workflow**, including editor extensions, debugging utilities, asset management tools, and reusable SOLID-based code examples.

The goal of this project is to **share practical Unity tools with the community** and help developers build projects faster.

---

## Tools Included

### Colorful Folder Structure
Improves the Unity Project window by adding **colored folder indicators**.

Features:
- Unique folder colors
- Better project organization
- Visual hierarchy in large projects

---

###  Custom Inspector Utilities
Custom inspector tools that improve the Unity Inspector experience.

Features:
- Toggle between **single view** and **show children view**
- Cleaner inspector UI
- Better component visualization

---

###  Useless Assets Finder
A tool that helps detect **unused assets** inside the Unity project.

Features:
- Scan project assets
- Identify files not used in scenes
- Helps reduce project size

---

###  Scene AudioClip Finder
Utility to find **AudioClips used within scenes**.

Features:
- Scans the active scene
- Lists AudioClip references
- Helps manage audio assets

---

###  Scene Search Tool
Adds a **search box for scene objects** to quickly locate GameObjects.

Features:
- Fast object search
- Better debugging workflow
- Improved scene navigation

---

##  Coding Principles

The code in this repository follows **clean architecture and SOLID principles**:

- Single Responsibility Principle
- Open/Closed Principle
- Dependency Inversion
- Modular design
- Reusable editor systems

The focus is to keep the tools **lightweight, extensible, and developer-friendly**.
